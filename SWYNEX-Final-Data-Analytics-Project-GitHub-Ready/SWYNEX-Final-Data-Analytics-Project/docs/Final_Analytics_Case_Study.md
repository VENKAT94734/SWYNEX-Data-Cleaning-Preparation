# Final Analytics Case Study
## Problem Statement
Transform imperfect customer transaction data into a reliable analytical dataset and communicate customer purchase behavior through an interactive dashboard.

## Dataset
Customer ID, name, gender, age, city, annual income, purchase date and purchase amount.

## Cleaning
Whitespace normalization, categorical standardization, numeric conversion, date conversion, duplicate removal and median imputation.

## Analysis
Descriptive statistics, city/gender comparisons, income versus purchase relationship, monthly trends, high-value customers and data-quality checks.

## Dashboard
Power BI design containing KPIs, slicers, city/gender charts, monthly trend, income-purchase scatter plot and Top 5 customers.

## Conclusion
The project demonstrates an end-to-end workflow from raw data preparation through exploratory analysis, dashboard design and business insights.
